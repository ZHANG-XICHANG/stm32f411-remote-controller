# LCD1602 I2C 使用方式

本驅動使用 `hi2c1`（PB6=SCL、PB7=SDA），I2C 維持目前的 100 kHz。
背板接線須為 P0=RS、P1=RW、P2=E、P3=高有效背光、P4～P7=D4～D7。
`MX_I2C1_Init()` 已在 `main()` 中呼叫；`StartDisplayTask()` 已在迴圈前呼叫
`Display_InitAndShowHello(&lcd)` 一次。此函式位於 `freertos.c` 的 USER CODE Application 區域，
包含 1500 ms 上電等待、`lcd1602_Init()` 及顯示 `Hello`。初始化函式內部會將成功或失敗結果
透過 `Debug_Print`／`Debug_Printf` 送往除錯佇列，呼叫端不需重複輸出；回傳值仍為 `HAL_StatusTypeDef`。
後續顯示操作可放在同一個 Task 的 USER CODE 區域；只有初始化成功後才進行顯示。

位址常數已符合 STM32 HAL 的左移格式：

| 常數 | 背板 7-bit 位址 | 傳給 HAL 的值 |
|---|---|---|
| `PCF8574_ADDRESS` | `0x27` | `0x4E` |
| `PCF8574A_ADDRESS` | `0x3F` | `0x7E` |

背板 A0～A2 可能設定成其他位址；請依實際模組選擇，這些常數不能再次左移。

目前任務會在初始化成功後，於第一行第一格寫入 `Hello` 一次；定位或文字傳輸失敗時會輸出除錯訊息。
以下是可取代目前初始化及顯示區塊的雙行測試畫面函式範例：

```c
#include "lcd1602_i2c.h"
#include "i2c.h"

static lcd1602_HandleTypeDef lcd = {0};

static HAL_StatusTypeDef LCD_TestScreen(void)
{
    HAL_StatusTypeDef status = lcd1602_Init(&lcd, &hi2c1, PCF8574_ADDRESS);
    if (status != HAL_OK) return status;

    status = lcd1602_SetCursor(&lcd, 0U, 0U);
    if (status != HAL_OK) return status;
    status = lcd1602_Print(&lcd, (const uint8_t *)"STM32 F411");
    if (status != HAL_OK) return status;

    status = lcd1602_SetCursor(&lcd, 0U, 1U);
    if (status != HAL_OK) return status;
    return lcd1602_Print(&lcd, (const uint8_t *)"LCD1602 ready");
}
```

所有公開函式現在回傳 `HAL_StatusTypeDef`，可直接檢查是否為 `HAL_OK`。
`lcd1602_Print()` 保留 `uint8_t` 字串介面，但改成 `const`，空字串不會傳送資料。
游標使用零起算的 column/row，只接受 0～15、0～1；不會自動換行。

I2C 傳輸失敗後 `lcd.initialized` 會變為 `false`，後續操作回傳 `HAL_ERROR`。
原因是失敗的傳輸可能只完成一半，LCD 的 4-bit 相位已無法確定；應先排除
位址／接線／匯流排問題，再呼叫 `lcd1602_Init()` 重新同步。
`HAL_OK` 表示位址 ACK 和指令傳送成功，不代表 LCD 顯示內容已讀回驗證。

延遲在 RTOS 運行時使用 `osDelay()`，排程器啟動前使用 `HAL_Delay()`。
API 仍為同步操作；不要在 ISR、臨界區或不同 Task 同時操作同一 LCD。
若 I2C1 也供其他裝置使用，呼叫端須協調匯流排存取。

初始化與 E 寫入序列依照 [HD44780U 規格書](https://www.sparkfun.com/datasheets/LCD/HD44780.pdf)
的 4-bit 初始化流程及寫入時序處理。程式保留上電和指令執行等待，移除了
原本兩段閃背光用的 500 ms 等待。PCF8574 介面規格見
[NXP 資料表](https://www.nxp.com/docs/en/data-sheet/PCF8574_PCF8574A.pdf)。

主機模擬測試的執行方式見 [tests/lcd1602/README.md](../tests/lcd1602/README.md)。
